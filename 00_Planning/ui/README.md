# UI reference

Layout A, the three-pane workspace of `../architecture/06-ui.md` §1, chosen on 2026-10-09 for being
simple and clear in its menus. These files are a visual reference for the M0–M2 UI work packages,
not a specification: where they differ from 06-ui.md, the spec wins.

| File | Content |
|---|---|
| [layout-a-workspace-light.png](layout-a-workspace-light.png) | session screen, light theme, 1440×900 |
| [layout-a-workspace-dark.png](layout-a-workspace-dark.png) | the same, dark theme |
| [layout-a-workspace-light.html](layout-a-workspace-light.html), [dark](layout-a-workspace-dark.html) | static HTML of the same screens; open in a browser to inspect sizes and colours |

The screen shows the demo workbench MC-200: the session list with status badges, a turn with three
tool rows and citation chips, an edit waiting for approval with its diff and `A`/`D` keys, the
composer disabled during the wait, and the Docs tab with index status.

Design canvas with the source of these mockups and the two rejected alternatives (B document-first,
C workbench cockpit): https://claude.ai/artifact/Nb6LL9Lknjho2KEzcLkXsC (private to its owner).
