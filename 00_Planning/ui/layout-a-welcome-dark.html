VERA

Open a workbench

A workbench is a folder with your board's documents, notes and skills. VERA works inside it and never outside it.

Create a workbench

VERA creates workbench.yaml, WORKBENCH.md, docs/ and skills/. An empty folder or an existing project folder both work.

Open an existing one

Pick a folder that already contains workbench.yaml, for example one a colleague shared or one kept in Git.
