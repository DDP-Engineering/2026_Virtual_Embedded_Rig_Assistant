# Streamline plugin installation confirmation

Install a new verified official package directly when its contents consist of skills and Markdown
documentation and it declares no programs, execution rules, required plugins or settings. Keep
catalog, manifest, package-integrity and platform checks and per-workbench activation.

Show required confirmation within the plugin library with the package, source, scope and relevant
programs, dependencies or risks. Keep full technical details on demand. Show the changed programs
and command rules for catalog updates requiring confirmation. Preserve the existing pack review
and direct updates whose programs and command rules match.

Validate the verified catalog and package boundaries, direct and confirmed install flows,
confirmation cancellation and failure, and update differences with focused tests.
