Metodă și limite

  • Evaluatorii de agent pornesc CLI-ul cu workbenchuri de test, propunerile de scriere neaprobate și conexiuni îngrădite. În safety, apelurile web sunt oferite modelului cu rețeaua blocată. Celelalte familii rulează independent de LM Studio.
  • Comparația principală folosește dovezile Qwen din 23 noiembrie. Pentru celelalte familii, istoricul provine din documentația evaluatorilor. Rezultatele unui singur model descriu combinația dintre VERA, model și server. Diferențele dintre cele două rulări pot include variația modelului și schimbări din alte commituri.
  • Timpii Qwen provin din turele evaluatorilor și includ răspunsul modelului și lucrul VERA. Rezultatele WSL2 sunt etichetate după mediul lor. Timpul măsurat pe host poate include variații de la alte activități ale sistemului. Dosarele aceleiași serii folosesc data pornirii suitei. Fiecare fișier JSON păstrează orele rulării individuale.
  • Rulările Windows au folosit codul urmărit din commitul publicat. Indicatorul Git dirty include arhivele neversionate ale pluginurilor, prezente anterior în directorul local. Pentru primele rulări WSL2, indicatorul reflectă doar permisiuni de execuție copiate pe patru fișiere de metadate și licențe, cu octeții neschimbați.
