# Synthetic I2C workbench

The only board is DEMO-RIG revision B, unit DEMO-01. The bench uses procedure BOOT-1 revision
2 with the fixture power supply, harness A and the same serial recorder for both runs.
The purpose is to compare startup in baseline firmware 1.0.0 and candidate firmware 1.1.0.

- Baseline 1.0.0: logs/baseline.log.
- Candidate 1.1.0: logs/candidate.log.
- Criterion and setup: docs/boot-test.md.
