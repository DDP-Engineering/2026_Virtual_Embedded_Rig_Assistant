# Test outputs

Evidence that functional tests and work packages leave behind for a person to inspect: screenshots,
receipts, original logs and platform probes, one folder per ticket or topic (for example `mask05/`,
`view03/`, `term04/`). Local helper environments of the test suite, such as the Python environment
for plugin tests (`plugin-test-python/`), also live here.

Everything here except this README is ignored by Git. Evidence that must be kept is added
deliberately with `git add -f`. Measurements and scores of the [evaluators](../evaluators/README.md)
do not belong here; they go to [`../evaluation-outputs/`](../evaluation-outputs/README.md).
