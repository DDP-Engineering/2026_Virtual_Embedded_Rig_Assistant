# Raccourcis clavier

Voici les raccourcis clavier par défaut de VERA. Modifiez-les, ajoutez-en ou supprimez-les dans **Paramètres → Raccourcis clavier** ; voir [Paramètres](settings.md).

| Action | Raccourci | Effet |
|---|---|---|
| Nouvelle session | Ctrl+N, Ctrl+Shift+O | Démarrer une conversation dans le banc de travail actif. |
| Nouveau banc de travail | Non attribué | Afficher le formulaire de création d’un banc de travail. |
| Ouvrir un banc de travail | Ctrl+O | Choisir et ouvrir un dossier de banc de travail. |
| Ouvrir les paramètres | Ctrl+, | Afficher les paramètres de l’application. |
| Raccourcis clavier | Ctrl+/ | Ouvre Paramètres → Raccourcis clavier. |
| Afficher/masquer la barre latérale | Ctrl+B, Ctrl+Shift+S | Afficher ou réduire la navigation des bancs de travail. |
| Afficher/masquer le panneau droit | Ctrl+Shift+B | Afficher ou masquer les panneaux Contexte, Fichiers et techniques. |
| Rechercher dans la conversation | Ctrl+F | Rechercher dans la transcription de la session en cours. |
| Activer la saisie du message | Non attribué | Placer le curseur dans la saisie du message en cours. |
| Activer le sélecteur de modèle | Ctrl+Shift+M | Sélectionner la commande du modèle dans la conversation. |
| Signet suivant | Ctrl+Alt+N | Aller au prochain message marqué dans cette conversation. |
| Signet précédent | Ctrl+Alt+P | Aller au message marqué précédent dans cette conversation. |

## Touches fixes

| Raccourci | Effet |
|---|---|
| F1 | Ouvre la page d’aide de l’écran actuel. |
| F10 | Passe aux menus Fichier, Édition et Affichage. |

Depuis un repère individuel ciblé, Tab atteint l’action de signet ; Entrée ou Espace la bascule. Échap ferme l’aperçu et ramène le focus au repère.

Ouvrez une exécution terminée avec **Ouvrir le journal** dans Exécutions. Les raccourcis du lecteur, dont **Ctrl+F**, **Ctrl+G** et **Ctrl+W**, fonctionnent aussi pour les journaux.
