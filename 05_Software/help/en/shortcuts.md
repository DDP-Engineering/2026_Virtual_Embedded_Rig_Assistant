# Keyboard shortcuts

These are VERA's default keyboard shortcuts. Change, add or remove them in **Settings → Keyboard shortcuts**; see [Settings](settings.md).

| Action | Shortcut | What it does |
|---|---|---|
| New session | Ctrl+N, Ctrl+Shift+O | Start a conversation in the active workbench. |
| New workbench | Unassigned | Show the form for creating a workbench. |
| Open workbench | Ctrl+O | Choose and open a workbench folder. |
| Open settings | Ctrl+, | Show application settings. |
| Keyboard shortcuts | Ctrl+/ | Open Settings → Keyboard shortcuts. |
| Toggle sidebar | Ctrl+B, Ctrl+Shift+S | Show or collapse the workbench navigation. |
| Toggle right panel | Ctrl+Shift+B | Show or hide Context, Files and technical panels. |
| Find in conversation | Ctrl+F | Search the current session transcript. |
| Focus message input | Unassigned | Move the cursor to the current message input. |
| Focus model selector | Ctrl+Shift+M | Select the model control in the conversation. |
| Next bookmark | Ctrl+Alt+N | Jump to the next bookmarked message in this conversation. |
| Previous bookmark | Ctrl+Alt+P | Jump to the previous bookmarked message in this conversation. |

## Fixed keys

| Shortcut | What it does |
|---|---|
| F1 | Open the help page of the current screen. |
| F10 | Move to the File, Edit and View menus. |

Tab from a focused single-message rail marker to its bookmark action; Enter or Space toggles it. Escape closes the preview and returns focus to the marker.
