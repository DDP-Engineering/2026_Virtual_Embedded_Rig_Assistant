# VERA help

VERA, the Virtual Embedded Rig Assistant, is a desktop workbench for embedded engineers. You open a project folder as a workbench, and VERA indexes its datasheets, manuals and notes on your computer. An AI agent answers your questions about the project and cites the pages it used; a citation opens the document at that place. Through plugins, the agent can also run the tools of your bench, such as flashing tools, serial monitors or debuggers, always under the permission mode you choose.

## Open help

- Select **?** in the top bar, next to **Toggle right panel**.
- Press F1 to open the help page of the screen you are on.

Help shows the list of pages and the selected page. Links between pages open the linked page inside Help.

Help is installed with VERA, so it works without network. It is shown in the interface language. When a page is not available in that language, the English page is shown instead.

## Ask the agent

The agent can read these help pages too. In any session, ask for example "How do I enable a plugin in VERA?" or "How do I export a session in VERA?", and it looks up the answer in help.

## Plugin help

Each installed plugin has its own help page: what the plugin does, what it needs and how to ask the agent to use it. You find it in Help, in the page list, and on the plugin's card on the **Plugins** page.
