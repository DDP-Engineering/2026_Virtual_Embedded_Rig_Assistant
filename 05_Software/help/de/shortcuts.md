# Tastenkürzel

Dies sind die Standard-Tastenkürzel von VERA. Ändern, ergänzen oder entfernen Sie sie unter **Einstellungen → Tastenkombinationen**; siehe [Einstellungen](settings.md).

| Aktion | Tastenkürzel | Funktion |
|---|---|---|
| Neue Sitzung | Ctrl+N, Ctrl+Shift+O | Eine Unterhaltung in der aktiven Workbench starten. |
| Neue Workbench | Nicht zugewiesen | Das Formular zum Erstellen einer Workbench anzeigen. |
| Workbench öffnen | Ctrl+O | Einen Workbench-Ordner auswählen und öffnen. |
| Einstellungen öffnen | Ctrl+, | Die Anwendungseinstellungen anzeigen. |
| Tastenkürzel | Ctrl+/ | Öffnet Einstellungen → Tastenkombinationen. |
| Seitenleiste umschalten | Ctrl+B, Ctrl+Shift+S | Die Workbench-Navigation ein- oder ausklappen. |
| Rechtes Panel umschalten | Ctrl+Shift+B | Context, Dateien und technische Panels ein- oder ausblenden. |
| In Unterhaltung suchen | Ctrl+F | Die Nachrichten der aktuellen Sitzung durchsuchen. |
| Nachrichteneingabe fokussieren | Nicht zugewiesen | Den Cursor in die aktuelle Nachrichteneingabe bewegen. |
| Modellauswahl fokussieren | Ctrl+Shift+M | Die Modellauswahl der Unterhaltung fokussieren. |

## Feste Tasten

| Tastenkürzel | Funktion |
|---|---|
| F1 | Öffnet die Hilfeseite des aktuellen Bildschirms. |
| F10 | Wechselt zu den Menüs Datei, Bearbeiten und Ansicht. |
