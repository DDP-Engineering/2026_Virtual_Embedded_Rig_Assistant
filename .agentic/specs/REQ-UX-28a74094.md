## Projection and state

Library state belongs to the renderer QueryClient (`ui/plugin-library`) for its lifetime, separately
from any workbench draft. Initial Available/recently-added/6 entries; each filter change resets page1.
Results shrink clamps the page only once the selected list has a loaded snapshot. Installed also
waits until catalog metadata settles, while catalog failure still permits offline management. The UI state key
uses infinite garbage-collection lifetime while catalog/list results keep their ordinary policy. Source identities use source/id/hash, not names. Catalog installation
state comes from catalog entries, while Installed preserves actual source/trust and issues.
Global folder/ZIP/trial imports retain reviewed catalog updates when the authoritative installed
version matches; scoped id collisions never receive those updates. Manual imports do not borrow
catalog classification/publication metadata or tier before an actual reviewed catalog install.

Search normalizes NFD/combining marks and case, splits whitespace and requires all words in the
combined name/id/description/ecosystem/localized activity labels/keywords. Ecosystem, activity,
provenance and state filters intersect. State counts honor other filters. Total tab counts stay total.

Unknown publication dates remain unknown. Recent sorts order known ISO days descending then
localized name/id/source. New means UTC calendar day age 0..29; age 30, future and unknown excluded.
Date unavailable is explicit in details; no build/install/cache timestamps stand in for publication.

## Dependency observations and actions

No browsing path calls programs/check/provision. Disabled Query observers read only explicit-check
observations keyed by active scope, plugin id, hash and install time. Before a check show Not checked.
Explicit Check/check-all/provision/archive results update that cache and all derived state filters.
A rejected check is Unavailable/error even after a previous Ready result; missing observations are
Not checked. Missing programs are Needs configuration. Archive cancellation keeps prior observations.
Check-all catches each package failure and continues, reporting counts and per-package diagnostics;
it never provisions. Invalid packages are shown, skipped by checks and retain diagnostics/review.

First installs and changing updates retain hash-bound review and dependency ordering. No unchanged
program/risk semantics are weakened. Cancelling/failing a queued review discards its remainder.
Manual install switches to Installed after completion so newly imported local packages are visible.
