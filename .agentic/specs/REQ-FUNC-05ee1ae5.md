# REQ-FUNC-05ee1ae5 — LLM gateway contract

## Behavior and interfaces

Core owns gateway/capabilities/model selection, api and empty subscription collections. Host injects current settings, CredentialStore, Clock, and scrub(text) over the process-lifetime WP08 registry. Each operation snapshots current provider config; conservative custom compat: supportsStore=false, supportsDeveloperRole=false, supportsReasoningEffort=false. Optional key uses a placeholder; OpenAI requires stored API credential, ambient process keys are not authentication. No telemetry exporter is installed.

Model reference is providerId/modelId, split at first slash (model IDs may contain slash). Provider IDs: openai, custom:slug, chatgpt reserved, replay test-only. Missing selection is INVALID. Capabilities expose contextWindow, maxOutputTokens=min(requested or effective maximum, effective maximum); OpenAI effective maximum=min(16384,catalog maximum,contextWindow-safetyMargin-1), custom effective maximum=configured maximum, safetyMargin=max(1024,ceil(context*0.05)), inputBudget=context-output-margin, supportsTools (custom configured/observed; OpenAI catalog tool-request behavior is measured by Test). Custom positive safe integers with positive inputBudget are validated before dispatch.

providers.models request {id} returns {models:[{reference,id,name,contextWindow,maxOutputTokens,safetyMargin,inputBudget,supportsTools?}], reachability:pass|skipped}. OpenAI returns the pinned static catalog offline by default; Test explicitly probes GET /models. Custom GET /models uses configured URL/credential; only404/405/501 mean unsupported. Custom discovered IDs use configured budgets; configured model remains available. Unknown/malformed/error listings are failures, not skipped. Public fields are projected and scrubbed. Discovered IDs must form valid model references; whitespace/newlines are malformed provider metadata and fail at the core catalog boundary. No redirects escape the configured endpoint origin.

providers.test request {id,model?} (optional model ID, not full ref) returns {steps:[{step:reachability|authentication|tools|streaming,status:pass|fail|skipped,error?:VeraError}]} exactly four rows. Reachability performs catalog listing; unsupported is skipped. Authentication completes Reply with OK, tool probe offers echo, and the streaming probe requests a complete multiword sentence and requires >1 nonempty text delta. A single-token authentication response can pass authentication; a coalesced single text chunk still fails streaming. Each completion succeeds only with a terminal successful assistant message; only an offered echo call with exactly the required string text and no additional properties passes tools. Authentication failure skips downstream steps; reachability failure still yields all rows. timeout30s and retries0; no context retry. Main records supportsTools for a tested custom configuration only if unchanged and writable, using existing serialized ProviderSettings queue.

Mapped errors: OFFLINE/errors.OFFLINE endpoint; PROVIDER/provider.auth (reason=auth), provider.rateLimit (reason=rate_limit,retryAfter optional), provider.context (reason=context), provider.failure (reason=provider,message scrubbed). Error request/response text including partial messages is scrubbed before leaving gateway. Known VeraError protocol fields remain valid; params and every provider-owned string are scrubbed. Network transport fetch wrapper captures HTTP status/retry-after/error-body classification before pi-ai flattens exceptions; no headers/body are logged or stored. Stream buffers a raw overlap tail before scrubbing text/tool deltas across chunk boundaries; sourceDeltas records cumulative actual nonempty provider text chunks for streaming measurement. Stream returns scrubbed text/tool deltas plus final pi-ai AssistantMessage, actual numeric usage and protocol discriminants retained; done and partial assistant timestamps use host Clock at terminal emission. Metadata and content signatures are recursively scrubbed; cancellation distinguishes aborted.

Replay scripts JSONL match/prompt/text/toolCalls(name,args), first-line match supports (?i), stateless step=assistant count since latest user. Resolve placeholders from successful tool result JSON including artifact:name. Deterministic IDs/Clock injected; text split into multiple deltas; no script is structured NOT_FOUND. Replay is dynamically imported only within compile-time __VERA_TEST__ block; instrumented VERA_REPLAY_DIR selects replay without settings mutation. Release output omits env marker, replay implementation and registration code. The main service accepts a generic injected LlmGateway; replay composition occurs entirely inside the compiled test branch. Automated Node tests install guard before app modules, E2E retains Node/Chromium guard.

The renderer mock exposes the deterministic mock-openai catalog before authentication with reachability skipped. Its Test probes auth separately, honors explicit model overrides, rejects unknown OpenAI fixture IDs and does not persist current-model capability for an alternate model.

Settings4 extends nullable defaultModel to validated reference; migrate0/1/2/3 to4 with original bytes backup, preserve extensions/identity/providers, protect>4. Workbench existing string model contract remains unchanged; helper validates when used. smoke:live launches the ordinary release Electron host with userData, invokes the same provider service/connection test internally and emits scrubbed results, without renderer key access; no test seam or real-provider automatic run.
