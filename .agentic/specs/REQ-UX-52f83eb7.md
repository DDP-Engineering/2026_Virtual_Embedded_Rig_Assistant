# Accessible renderer interactions and catalog coverage

Requirements: REQ-UX-52f83eb7, REQ-UX-b7eabce7; existing REQ-UX-4a040007 and REQ-TEST-4a040006 retain their acceptance contracts.

Global keyboard actions yield to open dialogs, handled/repeated/composing/AltGr events and shortcut recording. Exact modifiers are matched against confirmed app-wide bindings; unassigned combinations do not dispatch. The default Ctrl (or existing Meta support) + N uses current writable workbench/session admission; comma opens Settings. In a session, Ctrl+F opens/refocuses transcript search. Match counts and each matching message have localized accessible text; closing search restores transcript focus. Plain Escape confirms Stop only for an active writable turn with no pending mutation. Cancelling/closing the stop modal restores connected prior focus, with transcript fallback. Native modal cancellation retains its own precedence. Composer path-completion Escape keeps its existing local precedence.

Approval A/D uses the existing focused group, current immutable request digest, pending/decision/readOnly locks and Alt/Ctrl/Meta/repeat/composition guard. Panel tabs expose linked, stable panel IDs, one Tab stop and Left/Right/Home/End activation with focus. Selected buttons expose aria-current/selected/pressed and a font-weight change. The skip-content button focuses main without changing the confined URL.

Repeated Open/Edit/Remove/Test/Enabled controls include item identity in their accessible names and retain visible action wording. Document/text, diff and artifact scrollers accept focus for keyboard scrolling. The PDF view provides already-scrubbed host page text in a native disclosure; canvas navigation/search and exact bytes remain owned by the established viewer contract. Theme tokens style ordinary fields, and field borders use the input token.

Catalogs retain English key structure, placeholder multisets, errors and technical identifiers. Romanian uses `spațiu de lucru`, `skill`, `execuție`; German uses `Arbeitsbereich`, `Skill`, `Durchlauf` and informal `du`. Names such as .vera/WORKBENCH.md, SKILL.md, VERA-DEMO-01, datasheet-reader, log-analyst and bringup-checklist stay literal. The key checker proves key usage/completeness only; placeholder comparison and AI semantic inspection are separate evidence. Human native-language review remains required before release.

## Static colour calculation

Evidence: `02_Tools/cache/wp38-TASK-19512432/source-analysis.py` and its `source-analysis.json` list every exact foreground/background hex, ratio, threshold and source SHA256. The method linearizes opaque sRGB at 0.04045, uses luminance weights 0.2126/0.7152/0.0722 and `(Lmax + 0.05)/(Lmin + 0.05)`. Source token definitions are unchanged.

For **each theme**, text pairs are foreground, muted-foreground, primary and destructive against background/card/popover/secondary/muted/accent (24); primary-foreground/primary, accent-foreground/accent, card-foreground/card, popover-foreground/popover and secondary-foreground/secondary (5). Non-text pairs are ring/input against the same six surfaces (12). Total: 82 pairs; text threshold 4.5, control/focus threshold 3. The calculated minima are 5.233032 and 3.000799 respectively. All meet these source thresholds. The near-threshold input pair requires real pixel/zoom assessment; this calculation excludes PDF pixels, selection overlays, OS controls, forced colours and spatial focus visibility.
