# Session performance protocol

The canonical scope is00_Planning/plan/performance-regression.md.

`npm run perf:sessions -- run --mode quick|full --output <new report.json> [--cases <csv>] [--scenarios <csv>] [--reference <reference.json>]` builds an isolated compiled instrumented app. Quick has5 measured samples/case; full30. Optional reference comparison requires a complete calibrated reference. `calibrate --runs <report1,report2> --budgets <budgets.json> --output <new reference.json>` requires at least two compatible full runs. `compare --report <report.json> --reference <reference.json>` compares stored evidence. Output files are exclusive-create. Exit0: complete measurement/comparison pass;1: failed measurement/budget/regression;2: invalid arguments/evidence/reference. A measurement without reference is diagnostic, not a regression pass.

Reports and references use format1, strict finite nonnegative metrics and declared expected sample counts per selected case. No p95 in quick summaries. Full p95 is nearest rank ceil(.95*n)-1; median averages middle pair. Host identity is hashed; CPU/model/RAM/platform/runtime are metadata. Source identity includes HEAD, full dirty patch/untracked content hash and source/built-file hashes. Compatible comparisons require the same host/build mode/runtime, fixture/harness identity, viewport and scale; source revision can change.

Each case has loadMs, mainGapMs, rendererGapMs, storageMs, snapshotMs, mainHandlerMs, ipcMs, presentationMs and payloadBytes plus process memory context. End-to-end runner and renderer IPC clocks are local durations. Presentation is measured in renderer time after API receipt; timings overlap and include documented automation overhead. All timed samples require real content/cursor correctness, draft typing and history scrolling. Failed samples remain in reports and cannot be calibrated.

Calibration requires explicit absolute budgets for loadMs/mainGapMs/rendererGapMs. Per metric and case, derive relative tolerance from variation between the two run medians with a minimum10%, and noise allowance from variation plus minimum5ms. Compare candidate median to reference median plus max(relative allowance, absolute noise allowance); check absolute budgets against every sample maximum. Quick compares median/max only; full also compares p95. References retain all source-run samples and provenance. Baseline budget violations remain visible and prevent an absolute-budget pass.

Fixtures are generated in fixed20/200/2000-message tiers plus a200-message variant with64KiB completed tool previews, stored as real sessions/messages/events. Exact generator manifest is hashed. Session pairs support warm/cross setup. First-open each uses a fresh app process, never preloads its target. No OS cache flushing. Runtime probes exist only in a dedicated test/performance build; ordinary builds do not import them. Only owned report roots/profiles are written; no real model or external traffic.
