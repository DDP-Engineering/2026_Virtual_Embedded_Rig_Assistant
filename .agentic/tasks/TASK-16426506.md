## Design

**Approach.** STATED (#343) — Electron main owns on-demand provisioning and an independent visible Chromium process per VERA session. OBSERVED (Playwright 1.64.0 browsers.json, vendor Chrome for Testing archives) — revision 1248 pairs with Chromium 156.0.8078.4. Pin the platform archive byte count and SHA-256, and the extracted file-tree SHA-256. Stream the archive into sibling staging, verify before extracting with the existing confined ZIP reader, verify the tree, then publish by rename.

**Interfaces and data.** BrowserRuntime supplies an explicit provision, status, cancel and verified executable seam (REQ-FUNC-facf03ca, REQ-FUNC-8db3fff6, REQ-SEC-92a60a12, REQ-REL-b48a282e, REQ-REL-c0d8c2ab). BrowserHost keys owned sessions by workbench and session IDs. It asks BrowserNetworkPolicy for a per-session lease before any verification or launch. The default refuses and the lease can supply Chromium proxy configuration and attach to the untouched ephemeral context before any tab is exposed (REQ-SEC-c372d1ee). Browser failures carry a typed reason and recovery instruction for later localized presentation. The launcher uses Playwright's local pipe transport and visible sandbox-enabled Chromium with its own temporary user data plus a non-persistent context (REQ-PLAT-2dafaac0, REQ-REL-b3c5a310, REQ-DATA-d8426151).

**Files and test seams.** Browser main-process sources in `main/browser` own release pins, verification, provisioning, policy, launch, and host lifecycle. Desktop main owns shutdown and workbench transitions. Packager stages the pinned production dependency as an external runtime library. Clock-based host tests cover limits and drain (REQ-NFR-68c245d2, REQ-REL-7f4d1af6); runtime and launcher unit tests cover release checks and typed failures. VERA_TEST compiles in a controlled, intercepted fixture with no product IPC or renderer changes (REQ-TEST-dafabd63).

**Risks and open decisions.** INFERRED — Failed or cancelled provisioning leaves only owned staging to clean. Runtime corruption fails closed before launch. A closing session counts toward the host limit until all owned cleanup completes. Linux remains dependent on a graphical session, Chromium libraries and a working OS sandbox. Native host/package acceptance is evidence to gather.
