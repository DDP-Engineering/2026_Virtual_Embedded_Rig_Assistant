## Design

### Approach

- INFERRED R1 (REQ-FUNC-a1040002, REQ-FUNC-566e4205, REQ-FUNC-14c661ce): remove saved feedback text from PlanEditor's initial context; identify saved comments by commentId and derive their text from the current state on every render. Keep only an optional user-authored string locally: undefined means untouched, while an explicit string, including empty, is a real edit. Create uses that draft or empty text; Edit uses it or current saved text; Re-anchor always reads current saved text. Never fall back to initial saved text while the projection is hidden or the record is absent. This avoids stale disclosure without clearing actual typing or remounting the modal.
- INFERRED R2 (REQ-DATA-fa8543aa, REQ-FUNC-dfa01734): pointer capture distinguishes no valid fragment from a captured fragment plus projection epoch. At click, absent capture keeps ordinary whole-step behavior; a valid captured fragment keeps its exact target; an invalidated capture opens the selector without a target. Only explicit Use selected text/Entire step can then enable Save. Consume the pointer ref at opening; retain existing revision/occurrence/UTF16 checks.
- INFERRED R3 (REQ-SEC-bb8e4dce and spec D3): add a host-only WorkbenchService.readConfig() path that refreshes validated current disk config without catalog warnings. Review alone uses it before existing getPinned(); metadata keeps its snapshot path and ordinary preparation keeps getConfig(). Reject using a stale snapshot, suppressing warnings globally, or returning an invented empty warning list to ordinary consumers.

### Interfaces and data

- INFERRED R1 (REQ-FUNC-a1040002, REQ-FUNC-566e4205): PlanEditor carries action, commentId where applicable, anchor/capture metadata, expected feedback revision and opener, not a saved-text copy. Resolve the current saved record by ID in state.planComments; while unavailable hide its saved text and disable saved-comment mutations. User input remains local through refresh/error. Edit sends the displayed explicit user draft or current saved text through the existing edit payload/CAS; a removed comment cannot become a create. Re-anchor still sends target only (REQ-FUNC-14c661ce).
- INFERRED R2 (REQ-DATA-fa8543aa): represent no capture separately from a captured PlanTarget/projection; retain the latter even when it becomes invalid until click consumes it. Do not conflate its failed validation with no capture. A genuine no-fragment or cross-step selection remains the existing whole-step control, not the invalidated-valid-fragment case.
- INFERRED R3 (REQ-SEC-bb8e4dce; WorkbenchService serial-queue constraint): readConfig(): Promise<WorkbenchConfig> queues once and calls a private refreshConfig helper for the existing confined disk parse, identity check and state refresh. getConfig() queues once, uses the same helper and then computes warnings with its unchanged return shape. Neither queued public method calls the other, avoiding a self-wait deadlock. No warning discovery, writes or publication is added to readConfig; existing invalid YAML/identity/lifecycle errors propagate.
- INFERRED R3 (existing scoped-host contract): SessionsHost retains captured workbench/DB assertions before/after each awaited read and at effects. Existing IPC, feedback persistence, admission receipts, CAS/error codes, ownership, disabled tools and todo-only runtime stay unchanged. No stored format, dependency, quota, model capability or permission change.
