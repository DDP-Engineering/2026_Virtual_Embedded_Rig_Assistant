## Design

Requirements coverage: role/rules/order FUNC9441c5d6, pinned bytes DATA446edf2a, metadata FUNC2faac04b, environment FUNC76d8e0f2 and size UX6e2e647a attach to prompt.test.ts.

Interfaces/contracts: see spec. No defaults or side effects; session mode is explicit, workbench only supplies name.
Data/state: synchronous ephemeral result, no persistence; bytes and character units are separate. Date obtained once from injected port.
Execution: canonical rules constant, UTF8 byte-bounded scalar prefix only if oversized, optional metadata block, environment, text.length.
Failure/recovery: validated inputs and ordinary Clock Date contract; no new error protocol or I/O.
Security/trust: all eight canonical rules; tool descriptions remain schemas. No new imports across app boundaries, provider, sandbox/CSP or vera://app changes.
Ordering/concurrency: caller skill order preserved; independent invocations hold no shared state.
Compatibility: additive export, existing WP01-11 contracts unchanged.
Observability: text plus characters; deterministic snapshots.
Alternatives/tradeoffs: return object makes size explicit; UTC date portable across host timezone; scalar prefix prevents replacement at cut boundary rather than decoding partial UTF8.
Expected files: prompt.ts, index.ts, prompt.test.ts and snapshot; requirements/spec, journal, agent knowledge/project/architecture current-state reconciliation. No new dependency.
Risks: snapshots alone can approve incorrect rules, so literal-rule assertions supplement them; Unicode needs byte-oriented tests.
