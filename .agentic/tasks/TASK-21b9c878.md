### Interfaces and data
REQ-UX-17662553 adds nextBookmark/previousBookmark with Mod+Alt+N/P, using existing settings schema/editor and localized descriptions.
REQ-UX-5722a63f selects strictly after/before the current reading message in user-message order; no wrap, no destination is a no-op.
Use current scroll metrics or the latest successful manual/shortcut destination at its unchanged scroll offset when handling each command; commands yield to dialog, IME, repeat, capture and hidden document tabs through existing guards.
REQ-UX-5722a63f calls existing Transcript navigate; if an anchor is not mounted, request all rows and retry after measurement. Successful commands close popups, focus the owning lane marker and announce the ordinal; without overflow focus the transcript and retain its status live region.
REQ-UX-f62a82bc keeps 24px targets; only the visible mark becomes longer. Group count remains legible on the primary fill.

Focused navigator and shortcut tests cover any-member changes, navigation order/boundaries/guards and custom keys; browser/native acceptance covers real geometry and restart across four languages.
