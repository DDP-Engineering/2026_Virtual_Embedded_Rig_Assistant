## Design

**Approach.** Workbench overview renders the existing full summary and the exception disclosure in its Indexing card when visible (REQ-UX-32477693). Overview stacks its groups and reserves separate label and value space to let long paths wrap on the value side. Indexing figures flow to the right of Documents and index and wrap when needed. The model and permissions rows have no separate heading. Files uses the existing Reindex toolbar slot for a compact working icon and status description. Count guard and stopped recovery stay in Files (REQ-UX-28ad0003, REQ-UX-db99cdfe).

**Interfaces and data.** WorkbenchIndexDetails consumes the active id and lease through the existing status hook. Files and Overview read the same cached docs.list query and use coalesced document publication refresh. Shared reindex mutation keeps the existing command and pending/read-only checks. The sidebar retains its existing focus route and status source (REQ-FUNC-310efe8f).

**Files and test seams.** Workbench/App wire the visibility and card. WorkbenchIndexDetails owns exceptions and counts. FilesIndexControls owns the toolbar and recovery. Shared document query helpers own list refresh and Reindex. Update component and native browser coverage that previously looked for detailed status in Files.

**Risks and open decisions.** Overview stays mounted in the app for other responsibilities; only mount its index details when visible. The Files tree and Git status have independent query keys. Mismatched scope and older revisions are already rejected. No open decisions.

**Requirement map.** REQ-UX-32477693 maps to the overview card. REQ-UX-28ad0003 maps to the Files toolbar. REQ-FUNC-310efe8f maps to the shared lease-scoped status hook. REQ-UX-db99cdfe keeps the existing sidebar shortcut.
