## Design

### Approach
STATED: implement the accepted presentation-only proposal. OBSERVED: ActivityLog is independent.
REQ-UX-0165dafe: create pure transcript projection groups for consecutive routine tool items of the same non-null turn; non-tool/essential items delimit groups. Reuse existing tool disclosures inside groups. Never reorder assistant/user text. Empty finalized assistant placeholders with no citations carry no conversation content and are omitted only in Normal/Minimal (observed native tool-only replay).
REQ-UX-84087df1: approvals, failed tools, download cards and stopped-turn statuses render outside hidden technical rows. Preserve existing ApprovalCard and Retry semantics.
REQ-UX-91b1b112: Activity receives unchanged state/reasoning/updates. Minimal/Normal hide transient reasoning from main transcript; Activity retains it.

### Interfaces and data
REQ-DATA-4a830b9a: shared exported chatDetailSchema/type and chat config object default normal; patch/merge/warnings know chat. Format stays 1, no compatibility code.
REQ-UX-b94a613e: Chat section in shared New/Edit form; both payloads include chat.detail. Existing confirmed workbench snapshot flows App -> SessionWorkspace -> Transcript; optional component prop defaults normal.
Normal summaries use localized operation count and running status, with no raw command snippets until expansion. Minimal has one localized active status; interrupted turns show localized stop notices in all modes.

Shared workbench schema/tests; renderer App/form/create/editor/workspace/transcript and a projection helper; locales en/ro/de. New focused transcript/form tests plus core workbench service and native replay/create/save/cancel/restart acceptance.
