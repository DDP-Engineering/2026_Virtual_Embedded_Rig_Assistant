## Design

Diagrams: [diagram_TASK-3f5447b9.md](diagram_TASK-3f5447b9.md)

### Approach
Add a desktop host TerminalService owning node-pty processes; keep native loading in the host edge. Renderer uses xterm/FitAddon and strict user-only IPC for create/input/resize/close/consent. Core gets only a TerminalReader port, never PTY write authority (REQ-FUNC-62710c49, REQ-SEC-c1ba6fbf).
### Interfaces and data
Ephemeral UUID terminal IDs belong to the current workbench; no persistence or format change. Several bounded live tabs retain bounded raw output. Renderer polls full masked snapshots, appends a matching suffix and resets/replays when a snapshot changes its prefix; selecting a tab reconstructs its bounded display. Agent terminal_read accepts an optional terminal ID; omission lists only shared terminals. User consent defaults false; each grant change increments an epoch. Reads carry an internal lease checked synchronously at runtime publication before tool.done/transcript disclosure (REQ-SEC-17dac70f). Closing or workbench replacement immediately invalidates leases.
### Files and test seams
Shared terminal schemas/channels/catalog/shortcut; host terminals and PTY factory; core terminal-read/registry/session/runtime publication hook; renderer terminal-tab/Shell/App/mock/locales/help generator. Focused host/tool/IPC/renderer/runtime tests, real native PTY command and resize, extracted package smoke. Package closure includes node-pty native helpers and prunes foreign architectures (REQ-PLAT-72f8f627).
Linux interactive jobs use separate process groups: desktop terminal-processes scans `/proc` by the PTY session ID, signals all groups, rescans after the grace period and escalates with the shell last. Windows retains taskkill's descendant-tree cleanup. Native regression covers background jobs on terminal close, workbench replacement and app shutdown (REQ-FUNC-62710c49).
The PTY factory starts Linux cleanup promptly on shell exit and memoizes the original cleanup promise; later finished-tab close only awaits it and cannot rescan a retired numeric SID. Generic serialized-result truncation is accepted only as literal `truncated:true` and is published after grant checks.
### Risks and open decisions
Interactive terminals use user OS privileges and interactive shell flags, separate from run_command flags/lifetime. Existing shell selection setting and filtered environment apply. Raw VT output stays bounded in main; masking uses buffered text before disclosure and retains credential prefixes to prevent split-secret leaks. Agent output strips ANSI and uses the Program runs 12000-character tail. Native Ubuntu/clean install acceptance is unavailable and will be explicit.
### Requirement map
REQ-FUNC-62710c49: PTY lifecycle; REQ-SEC-c1ba6fbf: read-only port/per-ID consent; REQ-SEC-17dac70f: ownership epochs/publication; REQ-SEC-65cfbdc5: scrub/env; REQ-PLAT-72f8f627: packaged helpers; REQ-UX-269fabc4: tabs/shortcut/locales.
