## Design

### Approach
REQ-UX-7c3fd9a6: constrain html/body/root/shell to the viewport. Main is a min-height:0 flex column; page content owns overflow while session workspace fills remaining space, including when an update banner is present. Keep sidebar and title row stationary.
REQ-UX-1676bc64: retain the actual native conversation scroll container and follow behavior. A sibling left segmented rail replaces its visible native scrollbar and controls the same scrollTop. A content wrapper supplies ResizeObserver measurements; the rail is hidden for non-overflowing content.
### Interfaces and data
Renderer-only scroll metrics and pointer capture; no persisted format or IPC change. Rail exposes scrollbar semantics, localized label, percentage and Arrow/Page/Home/End keys. Wheel/touch remain native; reading older content suppresses following until returning to the bottom. Keyboard focus stays visible. No animation required.
### Files and test seams
styles.css, App.tsx (keep Plugins in the same scrollable page region), session/transcript.tsx and new transcript-scroll.tsx; en/ro/de labels; new tests/e2e/session-scroll.spec.ts plus existing workspace regression. Renderer/chat component knowledge updated in validation.
### Risks and open decisions
Prevent flex minimum-size overflow without clipping long Settings; reserve rail hit area outside message content. Observe viewport/content resizing and preserve input ownership for dialog and textarea. No migration or compatibility path.
### Requirement map
REQ-UX-7c3fd9a6: bounded shell and independently scrollable regional content. REQ-UX-1676bc64: segmented left scrollbar with native scrolling and accessible controls.
