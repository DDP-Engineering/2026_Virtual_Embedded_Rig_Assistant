## Design

**Approach** — Add four entries to the shared registry with an explicit `international` binding (REQ-FUNC-ba09d076, REQ-UX-69c26603). MiniMax uses the pinned Anthropic Messages adapter, including signed thinking blocks. Z.AI uses the pinned Chat Completions compatibility for GLM, with preserved thinking and tool streaming. MiniMax requests use the documented Messages path without the SDK beta query marker. Kimi's existing beta request path stays in use.

**Interfaces and data** — The existing selected preset, binding and route select one key slot (REQ-SEC-8c64ad8c). The registry gives each connection a manual catalog with explicit documented choices. MiniMax API profiles M3.1 Flash and M3. The MiniMax M Plan key uses the same international base with a separate profile list centered on the documented Flash model. Z.AI uses the two documented Chat Completions paths and profiles GLM-5.3 and GLM-5.3-Flash for both. The MiniMax profiles keep the documented 524288 output ceiling and the recommended 131072 VERA budget. Unprofiled manual IDs retain unverified capabilities (REQ-FUNC-34a1e459) and a generic Test result does not mark them verified.

**Files and test seams** — provider-presets.ts holds service records and exact profiles. curated-adapters.ts carries Z.AI compatibility and effort helpers; providers.ts supplies fixed transport, MiniMax payload settings and GLM native effort to the existing adapters. The desktop gateway fixture scripts signed Messages thinking and GLM reasoning plus two inference requests with a tool result, and verifies cancellation and failure (REQ-FUNC-9ce3dff0, REQ-REL-18b120db, REQ-REL-a7a7dfad). The Settings browser spec covers search, fixed endpoints, manual model choice and resetting drafts when switching offerings.

**Risks and open decisions** — Provider consoles are authoritative for entitlement. Both MiniMax key types use one URL. The registry validates the documented `sk-api-` and `sk-cp-` prefixes at save and inference (REQ-SEC-7c5a2c03). Z.AI documents keys that can use multiple endpoints and billing based on key class. VERA keeps slot and route immutable, documents where to get the correct key and never probes alternate routes. Z.AI limits Coding Plan use to officially supported tools and VERA is absent from its published list. The editor shows a localized eligibility note on selection and edit (REQ-UX-c1714074). Authenticated behavior is unverified under RULING-001.
