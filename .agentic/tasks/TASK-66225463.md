## Design

**Approach.** The plugin list retains real packages and removable synthetic selections. Only provider records from the package query render capabilities. The shared section renders once for a compatible installed ecosystem (REQ-UX-e8ceb590).

**Interfaces and data.** Confirmed empty inventory and draft show the localized empty text; existing editor offers a catalog shortcut. The App reuses the global Plugins detour and starts the global catalog without old filters, retaining the application's sort and page size. New Workbench uses the shared empty view. The owner keeps its draft and returns through the existing navigation (REQ-UX-e07790cb, REQ-UX-e5d617d7).

**Files and test seams.** WorkbenchPlugins owns the conditional display; WorkbenchSharedCapabilities owns the ecosystem check and availability text. App and WorkbenchEditor route the shortcut through the config form. Focused renderer tests cover missing, disabled, enabled and restored providers. An App test covers the shortcut and retains a draft.

**Risks and open decisions.** A synthetic card can remove an unavailable enabled ID. It must never appear as an installed provider. A failed inventory read keeps the retry flow. Tool allowance storage and skill/runtime admission stay independent (REQ-UX-69b54580).

**Requirement map.** REQ-UX-e8ceb590 governs provider blocks. REQ-UX-e07790cb governs the empty view and selection. REQ-UX-e5d617d7 governs detour ownership. REQ-UX-69b54580 remains the installed-card readiness contract.
