## Design

**Approach.** OBSERVED the shared evaluator runs the real CLI and VERA gateway, installs the official analysis plugin, and retains observed JSONL. Reuse it for scripted tools and guarded OpenAI-compatible model probes. Run native Windows saved-file operations in the same cases. Use the previous validated Desktop and live capture evidence at the scope it demonstrated.

**Interfaces and data.** REQ-TEST-0c9b8f38 binds each case's declared synthetic files to SHA-256 and copies only those bytes to a dedicated scratch workbench. A bad digest stops preparation before inference. REQ-TEST-01594e57 ties exact expected arguments and result facts to ordered typed tool operations. Each requested frame must be valid in VERA and originate in the expected file's structured result. Report data in UTF-8 bytes and count all tool proposals. REQ-TEST-f00ca925 observes synthetic canary forms in saved events and proxied model bodies, retaining only detection counts for the latter.

**Files and test seams.** Add the Wireshark family, case manifest and replay, a frozen empty trace, scoring and fixture preparation, and focused tooling tests. Add a family preparation option and bounded request recording to the shared runner and proxy. Reuse the native Wireshark test fixtures and document evidence for operators.

**Risks and open decisions.** The shared egress guard keeps external tools off. The family denies interactive approvals and limits real inference time and custom model requests. Native smoke and replay only analyze synthetic local files. Any missing request observation or model runtime metadata remains explicit. Existing model credentials are accessed only by an already authorized CLI configuration.

**Requirement map.** REQ-TEST-01594e57 maps to deterministic scoring and native CLI replay. REQ-TEST-f00ca925 maps to explicit non-disclosure observations and encoded marker tests. REQ-TEST-0c9b8f38 maps to digest verification and the mismatch test.
