## Design

**Approach**

- OBSERVED: SessionService owns admission and durable steering, ReferenceRuntime owns the raw transcript and ContextCompactor owns the derived request view.
- Store references on user messages and events. Hydrate a budgeted projection at the existing session/gateway boundary after compaction and durable admission (REQ-DATA-7c2f4fef, REQ-FUNC-eab5aa88, REQ-FUNC-e831e9a4).
- Estimate the projected image request shape and masking during context preflight without loading file bytes. Compaction substitutes path notes in the summary request and copies the notes into the derived history itself (REQ-FUNC-b35c45ad).

**Interfaces and data**

- Optional bounded `images` on the send request, user and queued events and user snapshot items. Allow image-only prompts. Text callers retain synchronous service admission (REQ-FUNC-27505fa1, REQ-FUNC-81c071bc).
- The asynchronous image admission path resolves only ordinary primary-workbench files, with no Bypass or additional-folder scope. Validate size, signature and decoding before publishing any message (REQ-SEC-a40a6fbc, REQ-FUNC-2af13bab, REQ-FUNC-f8f95254).
- Use the pinned sharp runtime already shipped by the application for PNG, JPEG, GIF and WebP. Transmit a display-oriented still image within 2048 px per side. The source remains unchanged. Recheck references at dispatch. If one has become unavailable, carry its path with an availability note (REQ-FUNC-eab5aa88).
- Markdown exports expose literal paths and JSON carries the path arrays. Existing text masking applies to provider path labels, published paths and exports (REQ-DATA-9a415426).

**Files and test seams**

- Shared request, event, state and error contracts, desktop handler, event projection and mock, core session attachment preparation plus ReferenceRuntime/ContextCompactor and export. A loopback OpenAI-compatible request test and focused codec, persistence, projection and compaction tests provide the oracles.

**Risks and open decisions**

- Provider image token prices vary. The budget uses a labeled per-image estimate when a provider counter is unavailable. Persisted and exported session data stays at format 1. Attachments are revalidated when read; completed compaction does not reload replaced images.
