## Design

REQ-DATA-154fb0af: add migration3 embeddings with FK cascade and full document_extractions; an epoch counter updated by SQL triggers invalidates worker cache on every vector/chunk mutation. Existing SQL/checksums stay immutable. DocumentsRepository.replaceChunks accepts validated extraction/model vectors and publishes them in the existing outer ingest transaction. Processor optionally embeds chunks before publication, exposes modelId/release(root); ingest retries unchanged content for mismatched/missing model rows. stopIngest releases the worker after draining.
REQ-FUNC-0e93fa45: separate EmbeddingHost from grep-only WorkerPool interface; host chooses compiled entry, resource models/manifest, serialized per-root persistent worker, deadline/abort/termination/replacement. Worker lazily loads local transformers/ORT and batches32; vector cache per root/epoch/model, normalized cosine top50. Search uses KeywordSearch plus one-based RRF60 and stable id ties. Validate glob before ranking; guarded result paths.
REQ-FUNC-cc209d7e: DocumentKnowledge owns db/root/optional embedding host and full extraction reads with current-source verification. ToolContext/SessionService get a read-class knowledge port; registry validates strict schemas. PDF issued refs are validated against current indexed pages/source for required replay; general parsers/chips deferred. CLI index/search share node ports/settings/workbench locks with unconditional cleanup, run supplies knowledge. Desktop supplies packaged/development resource root and same host; worker ships in release.
Proof selection: migration/repository/ingest/processor/search/tools/replay tests; immediate registry/storage/workbench/session/host/build/boundaries; real production eval and relevant native Electron ingest/CLI.
