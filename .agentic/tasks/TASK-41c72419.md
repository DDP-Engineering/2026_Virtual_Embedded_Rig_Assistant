## Design

**Approach.** OBSERVED: #401 emits typed packet and capture evidence and the session persists successful tool output. Extend the packet result with an opaque citation token bound to the capture, frame and dissection context. Route a completed assistant citation through the owning session and main-process desktop launch. Wireshark consumes a private, verified snapshot with the source file name where available.

**Interfaces and data.** Grant launch only for a cited result issued by `wireshark_capture` before the target assistant message. The strict IPC accepts session and message identifiers, the token and an optional user filter. Main uses the #401 path guard, stream hash, packet identity and offline TShark profile. Native Wireshark receives separate `-r`, `-g`, optional `-Y` and Decode As arguments. TShark verifies filter matching on the snapshot with the same decode rules, and VERA adds the frame to a hiding filter.

**Files and test seams.** Shared reference and IPC contracts, core Wireshark evidence, session lookup, main native launcher, and the renderer citation dialog. Focused tests exercise provenance, file and frame rejection, filter behavior and argv. Native acceptance covers the actual citation button and packet selection.

**Risks and open decisions.** Path changes cannot swap the private file Wireshark consumes. VERA deletes snapshots when either launch fails or the viewer closes while VERA is running. At startup it keeps snapshots with a live owner or viewer and reclaims its other identified snapshots. Wireshark uses an isolated profile and disabled name resolution to match offline verification. The final gate owns native Ubuntu per RULING-001.

**Requirement map.** REQ-FUNC-b89e6361 and REQ-SEC-7a9ce8b1 use typed tool provenance and exact file/frame identity. REQ-REL-518300cc maps to guarded snapshot errors. REQ-UX-87a0888e and REQ-REL-0a8b9af5 use bounded TShark verification. REQ-PLAT-0513a15b, REQ-REL-4c3d3779 and REQ-REL-a5107766 use native discovery and launch. REQ-UX-d766ee40 covers the dialog, its feedback and help.
