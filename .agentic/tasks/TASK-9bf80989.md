## Design

### Approach

OBSERVED — ordinary matching normalizes tokens and accumulates the highest risk. REQ-SEC-0beca242 adds an exact two-argument path after that matching, eligible only when a rule matches and none blocks. Help uses the program timeout or session ceiling. Ordinary matching keeps its notes, confirmation and timeout.

### Interfaces and data

REQ-DATA-c80ab568 adds optional `subcommandHelp: { flag: --help, commands: [capture] }` to a format-1 program. The allowed flags are `--help` and `-h`; one must be chosen explicitly. Commands are unique literal argv tokens, with no options or pattern syntax. Fixed command prefixes (including downloads), launchers, plan programs, file programs and Git argument rewriting are incompatible.

REQ-FUNC-8f4df41b makes draft lint call out the consequence for each declaration. The author must review the exact argument pair against a documented early help exit.

REQ-SEC-5fa5cd5e keeps catalog token checks on effective safe help. The existing maintainer mark binds the exact command line. REQ-FUNC-8af265ac and REQ-UX-13ab0006 present those literal command lines and the effective risk computed by the shared matcher in an expandable group for the declaring program.

### Files and test seams

Manifest schema and matcher unit tests cover input shape and classification. Program request preparation supplies the selected declaration, and both timeout consumers use the same classifier inputs. Program policy retains the existing trial, blocked and mode branches. Core authoring checks inspect the package without invoking a program.

REQ-FUNC-deae8eff adds exact help output ahead of dispatch in the shipped power-profile helper. The official manifest audit uses source evidence and an offline invocation test for vetted bundled script help. An ignored routing overlay sends the exact tool proposal through the actual evaluator, with approvals denied and a real capture proposal as the positive fault control.

### Risks and open decisions

STATED — maintain the original treatment of unverified vendors and report them. No physical operation is needed. Concurrent changes are outside the candidate, including the routing README, and mixed release files need ticket-only patches.

### Requirement map

REQ-SEC-0beca242 covers exact raw matching and both runtime consumers. REQ-FUNC-2819a97e preserves ordinary risk and notes. REQ-DATA-c80ab568 covers schema constraints. REQ-FUNC-deae8eff covers the early help exit. REQ-FUNC-8f4df41b covers the author warning and authoring skill.
