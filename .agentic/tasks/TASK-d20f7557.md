## Design

### Approach
OBSERVED: SessionHub already validates, sequences, records and publishes durable events; export archives all events.
INFERRED: reuse this path, adding a synchronous SessionService.bookmark mutation and a strict IPC channel.
REQ-FUNC-0cfb4e5a: validate ownership and writability, record in a SQLite transaction, publish after commit.
REQ-FUNC-f404af3a: snapshot bookmarkedMessageIds is a unique array representing a set; live reducer copies only this collection.

### Interfaces and data
STATED (#304): message.bookmarked {messageId, bookmarked}; session.bookmark {sessionId, messageId, bookmarked} returns {}.
REQ-SEC-65a6ec17: resolve target in this session's user/queued events; invalid role/ownership/unknown target yields INVALID, missing session NOT_FOUND.
REQ-SEC-2ca61d1b: existing writable check enforces workbench lock/read-only; archived session yields DENIED. Deleting yields BUSY. Active turns may bookmark durable queued/users.
REQ-DATA-c7e31f58: schema/format remain 1; JSON archive retains events. Markdown export marks bookmarked user headings.
REQ-SEC-d857f50f: event is a projection-only preference, never a message row or runtime input.

### Files and test seams
Shared events.ts, session-state.ts and ipc.ts own contracts; core sessions/service.ts owns mutation.
Main index.ts binds channel through SessionsHost; existing generic preload handles it. Mock sessions implements equivalent contract for later controls.
Shared reducer/schema tests, focused core bookmark tests using real SQLite/reopen and a validated invoke router, Markdown export assertion; immediate main/preload/mock consumers.
No UI affordances or localized labels are introduced by this persistence-only ticket; those ship in BKM-02/03. Four-language help and release notes document retained export metadata only.

### Risks and open decisions
OBSERVED: main snapshot sanitizer spreads existing fields and preserves bookmark IDs; event sanitization also preserves IDs.
INFERRED: bounded message identity and boolean validation follow strict existing IPC conventions. Transaction/publish ordering prevents observed uncommitted state.
UNKNOWN: native Ubuntu availability; WSL Linux evidence is labeled separately. No migration or compatibility behavior.

### Requirement map
REQ-FUNC-f404af3a: unique user-only reducer membership and copy-on-write tests.
REQ-FUNC-0cfb4e5a: transaction then hub publish, validated router and replay tests.
REQ-SEC-65a6ec17: per-session user event lookup and negative IPC tests.
REQ-SEC-2ca61d1b: writable/archive/deletion gates, read/export tests.
REQ-DATA-c7e31f58: reopen DB and archive/Markdown proof.
REQ-SEC-d857f50f: messages untouched; captured gateway request proof.
