## Design

Diagrams: [diagram_TASK-4912fc24.md](diagram_TASK-4912fc24.md)

### Approach

OBSERVED: core, provider and desktop/CLI presentation currently scrub separately.
Use host callbacks backed by createMaskingResolver at publication, never replace credentials.scrub globally.
REQ-FUNC-dd416ac8: tool publish calls the original synchronous authority hook before live redaction;
request views reapply agent masking to retained history when policy changes.
REQ-FUNC-a1040001: session wrapper handles fake/replay providers and provider request carries a live
output-choice callback; both preserve split-secret tails and always protect error diagnostics.
REQ-FUNC-a1040002: desktop and CLI session projection respect agent choice; typed protocol fields remain intact.

### Interfaces and data

SessionHost receives masking(area) and knownSecrets; defaults preserve on for agent/exports.
LlmRequest receives an optional live maskOutput callback, absent means on for connection tests.
ArtifactHost receives separate content projection and unconditional name guard.
REQ-FUNC-8bcce7ee: artifact bytes/hash derive from projected content inside the write queue.
REQ-FUNC-656d2343/REQ-SEC-17075aa1: native exports resolve choice after the picker and preserve destination confinement.
REQ-SEC-65cfbdc5: terminal recent/publish resolve agent independently of user runs, retain consent/lease checks.
No format changes, migrations or recovery of previously redacted data.

### Files and test seams

Core sessions/service, llm gateway/providers/stream-scrub and artifact store; desktop sessions/events/index,
artifacts/session-export/terminals; CLI run/replay composition. New focused masking tests plus existing
runtime, artifacts, exports, provider, terminal and immediate consumer tests. Native/replay acceptance
uses validated IPC, a real stored fixture secret and local fake transport, no external provider.

### Risks and open decisions

Policy changes during async work require resolution at publication; raw tool authority stays separate.
Partial VT sequences must remain pending even with agent off; existing OutputDecoder owns that behavior.
Provider failure text/logging/environment filtering remain unconditional (REQ-SEC-647da472/25008e88).
No open product decision; full suites/plugin system gate and exact-source delivery gate are coordinator-deferred.

MaskingContextPolicy projects message views before counting and historical compaction (REQ-NFR-8767cf78).
The dispatch boundary rechecks after durable publication and returns CONTEXT_LIMIT without provider
dispatch when live masking expansion cannot fit. CLI session model references use typed projection
and valid-reference fallback (REQ-FUNC-a1040002).

### Requirement map

The coverage table maps every requirement to the corresponding boundary above; item detail uses the
same session projector (REQ-FUNC-acaeb296). Existing security requirements are revised only where #283
explicitly authorizes conditional content disclosure.
