## Design

### Approach
OBSERVED the existing optionSyntax seam is opt-in and is already used by core preparation and prompt entries. Extend it with `git` (REQ-SEC-d55e8cad), projecting command roles before generic case-folding. Keep original raw argument values/order in classification/approvals/run-records; effective execution additionally inserts the mandatory no-ext-diff guard described in REQ-SEC-d55e8cad. Safe recognition is conservative; unfamiliar options on known builtins retain device-write. Unknown command names are treated as potential executable aliases/helpers and blocked rather than freely dispatched. No shell, config read or alias expansion is added.
### Interfaces and data
REQ-FUNC-bf50e98d uses the existing find provisioner, version probe >=2.40 and no download. REQ-SEC-752a9d20 uses the shared command parser and core execution-only no-ext-diff guard plus existing prefix/env substitution and a file in no-hooks so zip packaging retains the directory. All formats remain 1. Canonical projections use command names and semantic markers for listings, writes, discards and helper execution; manifest rules remain the highest-risk authority. Global options are parsed before the command; actual case-sensitive short bundles, values and -- operands cannot manufacture a safe command or suppress an escalation. Unknown globals fail closed as configuration/execution escapes.
### Files and test seams
REQ-SEC-d55e8cad: shared/git-options.ts, program-rules.ts and plugins.ts plus manifest. REQ-FUNC-b7b93850: plugins/git/{plugin.yaml,README.md,skills/*/SKILL.md}, catalog.yaml and packs.yaml. REQ-TEST-1dbaa57e: integration/git.test.ts uses installed catalog zip, real Git, NodeProcessHost, ProgramRunner, provisioner and SessionService/ReplayGateway. It records original evidence under one task/platform root; no external repository is mutated. Immediate consumers: matcher/schema/program preparation/catalog/import-boundary tests.
### Risks and open decisions
STATED Git is not a sandbox. Keep configured credential helpers and content filters; local textconv/filter residual risk remains. Explicit helper, pager/viewer/editor, signing, filter and configuration options are blocked. Fixed hooks/fsmonitor/pager/external diff do not disable all Git configuration; avoid promising that no program can ever execute. Tests isolate HOME/config/loopback 401 remote. Linux here is Ubuntu 24.04 WSL2; no bare-metal Ubuntu or ARM64 claim. No new lifecycle or database state.
### Requirement map
- REQ-FUNC-bf50e98d: find-only manifest, version/missing boundary fixtures.
- REQ-SEC-d55e8cad: command-specific projection + declarative highest-risk rules and matrix.
- REQ-SEC-752a9d20: fixed prefix/env plus mandatory execution guard and catalog round-trip process-exit/patch/marker fixture.
- REQ-FUNC-8e22989a: fixed guard at command boundary; raw request/file binding/log arguments preserved.
- REQ-FUNC-b7b93850: SkillCatalog discovery and workflow documentation.
- REQ-TEST-1dbaa57e: replay inspection/approval/commit and controlled credential failure.
