## Design

### Approach
REQ-FUNC-a7ad5920: add bypass to the canonical permission enum and reuse it for workbench defaults. Session tool contexts expose current mode and a revocable Bypass signal. PathGuard gains an explicitly host-selected filesystem scope allowing absolute/parent/ignored ordinary paths; default remains confined. Grep task scope is host metadata, separate from strict model args. Preserve canonical paths/fingerprints/atomic writes and output/binary limits. External read/grep results carry absolute paths without fabricating confined citations. Record Bypass changes with absolute paths for hash-only recovery.
REQ-FUNC-a7ad5920 and SEC contracts: ApprovalGate automatically grants Bypass requests, including protected metadata, retaining exact hashes and single-use consumption. Filesystem-scoped grants require current Bypass. Switching into Bypass resolves existing ordinary approval waits; switching out aborts scoped work and re-confines later calls. Existing injected host permission policies remain authoritative.
REQ-UX-33b9d601: shared PermissionPicker in composer and workbench Agent settings, with warning marker plus red/bold selected styling. Selection applies mode, then displays the informational modal; Close/X/Escape restore picker focus. No extra activation approval flow.
REQ-UX-bb147586: optional typed suppressBypassWarning application preference. The checkbox is saved on dismissal, with visible errors on failed persistence and read-only settings disabling preference writes. Suppression affects the notice only; Bypass remains marked.
### Interfaces and data
Current session/workbench mode gains bypass; no SQL/schema migration. Optional settings preference uses the current settings schema. Tool context supplies live mode/signal; worker task optional scope is host-controlled. Prepared filesystem requests mark their scope and persist absolute change paths. Disabled tools, OS rights, workbench read-only/ownership, binary/size limits and log redaction remain unchanged. Indexed document and citation viewers remain workbench-scoped.
### Files and test seams
Shared session/workbench/settings; core agent approvals/prompt, sessions service, tools context/registry/read/list/glob/grep/discovery/changes, PathGuard and worker host/task types; renderer PermissionPicker plus composer/editor/styles/locales/mock. Focused core Bypass/approval/path/worker tests and native replay prove real outside file operations and revocation. Browser/native UI tests cover selection, Close/X/Escape, translations and suppression/restart.
### Risks and open decisions
Full access can corrupt user files: explicitly requested and disclosed in the notice. Tests use owned temporary files only. Scope never comes from model arguments. Check current mode before admission and around I/O; abort in-flight Bypass reads/grep on downgrade. Hash-only recovery inspects recorded canonical absolute targets and never rewrites their content. No open product decision.
### Requirement map
FUNC-a7ad5920: host-selected filesystem scope, durable automatic grants and revocation. UX-33b9d601: reusable marked selector/warning. UX-bb147586: confirmed app preference. SEC-c370e45b/294dcab2: existing mode behavior plus explicit user-authorized Bypass exception.
