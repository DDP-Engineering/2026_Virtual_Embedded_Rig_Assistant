## Design

### Approach

OBSERVED: the offline service already gates the official plugin, snapshots the capture,
isolates TShark, and issues content-bound citations. REQ-FUNC-3cdfc800 adds one
`network` dispatch and a finite profile registry. Native traffic facts supply frame
identity and structured fields. Use existing directional grouping for TCP and UDP.

### Interfaces and data

REQ-FUNC-3cdfc800 selects a profile, an optional observation query, filter, and scan
and page limits. Expose address/name exchanges, TCP/UDP conversations, TCP symptoms
and multicast. Native DNS links are verified against the scanned counterpart and
context. Address resolution and DHCP expose observed addressing and transaction
attributes for correlation. REQ-DATA-fe4b7a36 reuses verified source and citation schemas
with a bounded shared row/evidence contract and a query-bound cursor. Native assembly
links are checked against the scanned section, interface and VLAN stack. Same-context
related frames can be cited outside the filter, and unknown context can withhold
decoded DNS/TLS fields.

### Files and test seams

OBSERVED: the shared tool schema, native reader, model projection and citation
registry are the normal boundaries. Add networking profile, projection and query
modules. Extend the Wireshark plugin replay with independently constructed packets
and native field comparisons. Exercise unsupported fields at the native boundary.

### Risks and open decisions

REQ-REL-fe778b38 preserves gaps, offload, truncation, opaque TLS, observation
points and drop metadata as observations. REQ-REL-baf79e3d reports the native
version and selected fields on unsupported dissection. REQ-SEC-22b9e089 confines
selection to metadata, rejects embedded-secret blocks before native reads, masks
network identifiers in the compact view and preserves the configured agent mask.
Compact publication hides path and filter. Exact navigation uses private context
from the successful local tool invocation and revalidates the published frame ref.
Round-trip and recovery projections keep the private context outside the transcript.

### Requirement map

- REQ-FUNC-3cdfc800: profile and grouping replay.
- REQ-DATA-fe4b7a36: frame citation and cursor assertions.
- REQ-REL-fe778b38: prefix, truncation, loss-marker, drops and TLS replay.
- REQ-REL-baf79e3d: native unsupported-field test.
- REQ-SEC-22b9e089: masking, metadata allowlist and secret-block replay.
