## Design

**Approach:** REQ-UX-b940c323: render completed, decided external approvals as native closed disclosures, leaving existing tool rows and order intact. Pending and running calls remain expanded (REQ-UX-9744e270). Use a separate summary rather than merging across calls to preserve chronology (REQ-UX-0165dafe).

**Interfaces and data:** Transcript passes tool completion to the approval card. A decision alone is not evidence that the call has completed. Disclosure is renderer-local state, with no changes to approval authority, errors or stored data.

**Files and test seams:** approval-card.tsx and transcript.tsx for rendering, styles.css and four locale catalogs for label styling, approval-card and transcript tests for pending, running, completed, and expansion. Changelog and release notes record the user-facing change.

**Risks and open decisions:** pending security information, confirmation, keyboard and actions remain visible and unchanged. Errors must remain visible outside a collapsed approval. No migration or new dependency.

**Requirement map:** REQ-UX-b940c323: closed disclosure for completed decided calls; REQ-UX-a4269b42: semantic labels and values with distinct styling; REQ-UX-9744e270: unchanged expanded pending card; REQ-UX-0165dafe: unchanged projection and chronological order.
