## Design

Diagrams: [TASK-71300a15 diagrams](diagram_TASK-71300a15.md)

### Approach

Find-only package `stm32-cubeprog` (program `stm32_programmer_cli`) plus a shared projection `stm32RuleArguments` selected by `optionSyntax: stm32cubeprog` (named seam, as for tshark and pymcuprog). Each recognized command becomes its canonical lowercase short name (aliases folded: `--optionbytes`→`-ob`, `--download`/`-d`/`--write`→`-w`, `--upload`/`-u`/`--read`→`-r`, `-s`/`--start`/`--go`→`-g`, `-setoem1key`→`-lockrdp1` ...), followed by a qualifier where one command has two risks: `-ob displ` vs `-ob <write>`, `-otp displ` (with optional `word=`) vs `-otp <write>`, `-psrss displ` vs `-psrss <write>`, `-corereg <write>` when an argument holds `=`, `debugauth` for any word starting debugauth except debugauth=2, wherever it stands; a board-free listing (every argument st-link-only/stlink-only/uart/usb) is `<list-only>` instead of `-l`. Words are lower-cased and, as a deliberate fail-closed choice, split at white space (the CLI only trims words); a number (-1, -0.5, -0x10) is an argument, any other dash word may be a command; words after a command (including -1 style numbers) are its arguments. OBSERVED (review round 1 probes): the CLI accepts extra leading dashes (`--rdu`, `---fchecksum`) and trims spaces, and `-file-checksum` reached another command, so a dash word the help does not spell exactly is `<unknown>` plus every command its dash-stripped name or its parts between non-alphanumeric characters name (fail closed; the CLI rejects or crashes on `=`, `/`, `\`, `:`, `,`); a word before the first command is `<unknown>`. Rules name the commands, so the typed word is the command (REQ-SEC-08036a89). Raw argv is executed and shown unchanged. Rejected: raw rules (cannot lower `-ob displ`).

### Interfaces and data

Rules (REQ-SEC-967391b8, REQ-SEC-08036a89, REQ-SEC-248961d6): safe `-h -version -q -log -vb -y -sl -ms -fchecksum -tm -ra -nv --skiperase -noreconnect -force_no_da -el -elbl` and `<list-only>`; device-read `-c -l -gettargetsellist -r -r32 -r16 -r8 -r32fast -checksum -v -blankcheck -score -halt -run -step -rst -hardrst -rstbl -corereg -ob displ -otp displ -psrss displ -getuid64 -fusgetstate -fusopgetversion -rssgetversion -hsmgetinfo -hsmgetcounter -hsmgetfwid -hsmgetstatus -regdump -hf -swv -startswv -p -gc -ssigfoxc -rp -detach`; device-write `-w -w32 -w16 -w8 -e -fillmemory -corereg <write> -g -wsigfoxc -wb -startfus -fwdelete -startwirelessstack -w32dbgmcu -a -rsse -mcsv -ecsv -rssekw` and `<unknown>`; irreversible `-ob <write> -rdu -tzenreg -lockrdp1 -unlockrdp1 -lockrdp2 -unlockrdp2 -otp <write> -storekeyotp -sfi -ssfi -ssp -installipmodule -updateipmodule -dsecurity -setdefaultob -antirollback -fwupgrade -authkeyupdate -authkeylock -wusrkey -sdp -pwd -psrss <write> -obrss -pmic -hsmgetlicense -hsmglfcb -pwr debugauth`; blocked `-script`.
