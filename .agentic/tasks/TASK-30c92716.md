## Design

**Approach.** OBSERVED — BrowserHost owns Chromium and its lease. Keep the
new browser port structural and Electron-free in core. SessionService binds
one port to a trusted owner from Desktop SessionsHost. The registry and
ReferenceRuntime check live permission before each model dispatch and call
(REQ-SEC-a3c7aa38). Each port serializes operations on its session and only
its owned context pages (REQ-FUNC-d219825f).

**Interfaces and data.** STATED — Seven strict schemas, for open, snapshot,
follow, scroll, tabs, switch and close. A session queue, opaque tab IDs,
main-frame navigation epochs, and an opaque token per snapshot prevent reuse
across revisions, tabs and sessions (REQ-SEC-2a1b6fb6). The fixed DOM reader
uses a Chromium isolated world, bounds traversal and returns viewport text,
title and human-readable links as untrusted data, with a canonical final
citation URL (REQ-FUNC-072acfac, REQ-SEC-ad60d613). Model arguments never
select browser evaluation or grant operations. Proxy and adapter distinguish
policy denials and unsupported content (REQ-SEC-fcab766f, REQ-REL-48dddd59).
Closed tabs and deadlines return stable codes (REQ-REL-7274a3e9,
REQ-REL-d97264a7). Use the model tool cap, separate smaller browser projection
and a browser session admission limit (REQ-NFR-2661da07).

**Files and test seams.** Core tool registry, tool/runtime types and Desktop
session composition, plus browser agent adapter and page reader. Runtime
mocks cover authorization and budgets; native replay covers the same public
proxy with controlled upstream fixtures. Existing web tests retain scope.

**Risks and open decisions.** Cancel a queued call immediately and close the
owning browser if active Playwright work reaches its deadline or is aborted
(REQ-REL-fff52da3). Close always releases its lease and handles
(REQ-REL-c8d7898f). BRW-04 can project a read-only activity snapshot from
BrowserHost by trusted workbench and session owner. Publish changes on
attach, authorized navigation, selection, page close and cleanup. Validate
ownership again on UI refresh and IPC commands. Grant and revoke stay in
BrowserAccessPolicy, and close stays in BrowserHost. Route Stop through the
normal turn cancellation signal. UI and new IPC are BRW-04 scope.
