## Design

### Approach

OBSERVED: #401 already provides isolated native execution, source snapshots and managed binary references. Extend those seams with `capture-files` orchestration, a byte-level `capture-file-index`, `capture-file-transform`, and `capture-file-export`. Capinfos supplies measured counts, format and hash. Editcap selects, converts, deduplicates and cleans. Mergecap joins chronological runs without retiming. Verify packet bytes, wire lengths, link types and timestamps independently before publication (REQ-FUNC-51a33002 through REQ-FUNC-51a33009, REQ-DATA-51a33010).

### Interfaces and data

- Add typed metadata and a separate session-class `wireshark_derive` entry. Existing capability output reports per-operation utility requirements. Preserve current TShark analysis path (REQ-FUNC-51a33001).
- Default to PCAPNG. Use bounded snapshots and binary stdout, private host-generated names and explicit time and deduplication boundaries. Retain full verified maps in a content-addressed lineage companion with bounded preview, explicit ambiguity and paged reads. Stage and reverify the complete batch under the workbench write queue before publication (REQ-DATA-51a33010 and REQ-SEC-51a33013).
- Fields and HTTP body records use bounded local JSON artifacts and fail closed when live export masking would alter their structure. TShark PDU taps produce a verified managed binary. Report missing metadata, refuse unindexed record kinds and distinguish incomplete exports from validated complete derivations (REQ-FUNC-51a33011 and REQ-REL-51a33012).

### Files and test seams

- Shared schemas, registry, masking, official manifest/skills and renderer labels compose the operations. Focused Wireshark plugin fixture tests run Windows utilities and assert metadata, exact packet/output provenance, normal analysis reuse and synthetic cleanup. Storage tests exercise batch rollback/revocation.

### Risks and open decisions

- Native output and capture structure are trust boundaries. Identical packets tied in a merge can have ambiguous ancestry. Ambiguous or unsupported native representations must remain explicit. Timestamped operations require timestamp data. PDU export is capture-level evidence unless the native result establishes a frame mapping.

### Requirement map

- REQ-FUNC-51a33001 uses independent native discovery. REQ-FUNC-51a33002 combines capinfos with the independent index. REQ-FUNC-51a33003 through REQ-FUNC-51a33009 use bounded native transformations and per-operation output oracles.
- REQ-DATA-51a33010 uses the existing storage contract and batch admission. REQ-FUNC-51a33011 uses typed, bounded native exports. REQ-REL-51a33012 and REQ-SEC-51a33013 use diagnostics, cancellation, scratch confinement and fail-closed publication.
